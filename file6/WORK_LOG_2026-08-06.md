## 4. アカウント作成フロー（重要リファレンス）

すべての招待は **1つの Edge Function `bright-endpoint`** を経由する（`grade-test` とは別物）。この関数が (1) Supabase Auth のログインアカウント作成 と (2) 招待メール送信 を行う。

```
Super → 施設＋管理者を追加 → bright-endpoint(role: facility) → 管理者に招待メール
         招待メールのリンク → login.html が type=invite を検知 → 「パスワード設定」画面
         → パスワード設定 = 初回ログイン完了 → 各ロールのアプリへ
Facility/Star2 → 「育成」タブから Star1 を追加（mentored_by=自分）→ bright-endpoint(role: star1)
         → Star1 に同じ招待メール → 同じパスワード設定フロー
```

- 「ログインリンク」と「パスワード設定」は**同一**。パスワード設定＝初回ログイン。次回以降はメール＋パスワードで通常ログイン。
- 招待リダイレクト先: `https://egym-master.vercel.app/login.html`（Redirect URLs 許可が必須 → 本日設定済み）。
- パスワード再設定は `login.html` の `resetPasswordForEmail` が `window.location.origin + '/login.html'` を使用。
